# Mon Carnet Vidéoludique — Multivers Gaming

Un carnet personnel pour organiser sa collection de jeux, conserver ses souvenirs et suivre son parcours vidéoludique.

## Fonctionnalités

- Collection de jeux, consoles et accessoires, avec recherche et filtres.
- Wishlist avec estimation manuelle du budget et vitrine de jeux favoris.
- Journal, sessions de jeu et statistiques.
- Quêtes personnelles, 103 succès et carillon original.
- Sauvegardes automatiques, restauration et export/import JSON.
- Recherche de jaquettes SteamGridDB avec clé enregistrée séparément.

## Versions bêta

Les éditions sont destinées aux bêta-testeurs. Les fichiers seront disponibles dans [Releases](https://github.com/HunterGourmet/mon-carnet-videoludique-beta/releases).

Systèmes proposés : macOS Apple Silicon et Windows x64. Avant de remplacer l’application, exportez votre JSON, vérifiez le fichier, puis fermez le carnet. La collection est conservée dans le même dossier entre les éditions bureau compatibles.

Les paquets actuels sont des éditions de test : signature locale sur macOS, sans Developer ID ni authentification Apple ; aucun certificat d’éditeur Windows. Les mises à jour en ligne de la bêta 0.7 restent désactivées.

## Retours des testeurs

Signalez les problèmes dans [Issues](https://github.com/HunterGourmet/mon-carnet-videoludique-beta/issues), en indiquant la version du carnet, le système, les étapes et le résultat attendu. Les signalements sont publics : ne joignez aucune clé API ni donnée personnelle.
